# Аудиозаписи авторского чтения стихов

Для синхронизации чтения стиха с физическим пером положите сюда файлы:

1. `artist-voice.mp3` — аудиозапись поэмы «Художник» (Часть I)
2. `threads-voice.mp3` — аудиозапись стихотворения «Нити на ветру» (Часть II)

Если файлов пока нет, сайт автоматически использует встроенный плавный генератор каллиграфического письма и дыхания речи в такт тексту стиха.
