# Художник — тёмная поэма

Интерактивный сайт-поэма с тёмной эстетикой, прогрессом чтения и анимациями.

## Стек

- Vite + React 19 + TypeScript
- Tailwind CSS
- Deploy-ready для Vercel

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой на Vercel

1. Зайди на [vercel.com](https://vercel.com) и подключи этот репозиторий.
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Deploy.

Готово — сайт будет доступен по ссылке Vercel.
